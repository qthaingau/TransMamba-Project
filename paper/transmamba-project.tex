% ABSTRACT

\begin{abstract}
While dense Transformer architectures remain foundational for various sequence understanding tasks, their characteristic $\mathcal{O}(n^2)$ computational and memory complexity imposes operational constraints when processing extended inputs. Recent frameworks utilizing Selective State Space Models (SSMs), notably Mamba, aim to establish a linear time scaling $\mathcal{O}(n)$ alternative while seeking to maintain comparable performance. This paper presents a local, small-scale empirical evaluation investigating the behavioral characteristics of three distinct sequence modeling paradigms: a dense pre-trained Transformer (DeBERTa), a patch-based structural approximation (PatchTST), and a Selective SSM (Mamba). Our evaluations are bounded to text classification tasks executed across sequence lengths ranging from 256 to 2048 tokens using the AG News benchmark dataset under standardized local academic compute constraints. The empirical data highlights clear resource trade-offs: while the pre-trained dense baseline exhibits strong contextual priors within shorter sequences, it encounters strict hardware barriers at higher sequence capacities, culminating in Out-of-Memory (OOM) status at 2048 tokens. Conversely, the patch-based mechanism avoids excessive memory overhead but demonstrates a observable compromise in classification accuracy. Within the limited scope of this preliminary university experiment, Mamba-Cls demonstrates stable memory retention ($\sim$151MB VRAM) and consistent throughput levels across scaling inputs, pointing toward its practical utility as a resource-efficient baseline for academic environments with restricted hardware accessibility.

\end{abstract}

% 1. INTRODUCTION

\section{Introduction}
Deep learning architectures tailored for Natural Language Processing (NLP) have historically relied upon token-to-token attention mechanisms to capture contextual dependencies across sentences \cite{vaswani,minaee,bert}. The core self-attention paradigm within dense Transformer frameworks distributes compute over all available tokens simultaneously. While this comprehensive mapping enables high fidelity in semantic correlation, it inherently scales quadratically ($\mathcal{O}(n^2)$) relative to the sequence token count. For localized research laboratories or university-level projects characterized by finite GPU clusters, this quadratic growth path acts as a technical constraint \cite{lora}, often necessitating string cutting, token pruning, or structural approximation methods to prevent terminal execution errors \cite{efficient_transformers}.

To address these hardware scaling limitations, architectural adaptations have entered recent research focus. Borrowing paradigms validated within computer vision fields, token aggregation strategies like PatchTST downscale long 1D textual distributions into overlapping or structured localized sub-sections (patches) \cite{patchtst}. This partitioning limits the computational matrix overhead to a collection of discrete zones, effectively reducing active Graphics Processing Unit (GPU) footprint during operational loops. However, imposing structural patch separations may inadvertently introduce boundaries that obstruct long-range linguistic continuity, potentially lowering total performance metrics on downstream document-level categorization.

Parallel to attention-focused variations, Structured State Space Models (SSMs) have been introduced as alternative continuous-time sequence processing options. Building upon foundational continuous sequence frameworks like the S4 model \cite{s4} and its text-capable successors such as H3 \cite{h3}, the Mamba architecture advances this path by incorporating a data-dependent, input-selective parameter alignment loop \cite{mamba}. Unlike static traditional state space representations, this dynamic filtering system compresses sequence historical details down to an optimized constant vector size, establishing a theoretical linear processing scale ($\mathcal{O}(n)$) that mimics recurrent sequence architectures while maintaining execution parallelization during training cycles.

While continuous analytical validation supports the asymptotic efficiency of Mamba, comparative empirical data evaluating its performance against pre-trained dense baselines and patched Transformer variants specifically within classification boundaries remains selective. Key operational variables, including initialization performance differences and hardware limits under strict single-node GPU execution scenarios, require localized validation.

This paper outlines a small-scale, university-level practical benchmark designed to chart these cross-architectural realities. By training and validating DeBERTa \cite{deberta}, PatchTST, and Mamba models using identical physical computational nodes on the four-class AG News text dataset \cite{agnews} across controlled context boundaries ($L \in \{256, 512, 1024, 2048\}$), we track the real-world boundaries dividing mathematical scaling laws from actual execution throughput.

The localized contributions of this empirical exercise are structured as follows:
\begin{enumerate}
    \item We detail a replication matrix tracking the memory expansion and internal processing velocities of dense attention architectures under practical resource limits.
    \item We quantify the accuracy adjustments that manifest when moving from dense token representations toward patch-based sequence constraints within text tasks.
    \item We record the empirical scalability profiles of Mamba under local conditions, evaluating its prospective role as a sustainable modeling framework for local student and departmental research groups.
\end{enumerate}

\section{Methodology}
Our empirical protocol relies upon three distinct network configurations designed to model sequential relationships through fundamentally different structural operations.

\subsection{Dense Transformer Baseline (DeBERTa-v3)}
As a representative baseline for dense attention modeling, we select DeBERTa-v3 \cite{deberta}. This iteration refines basic Transformer methods by introducing a disentangled attention matrix format alongside a relative positional encoding schema. DeBERTa serves as a performance reference point owing to its substantial pre-training data history. However, its complete dependency on full-matrix attention structures implies an $\mathcal{O}(n^2)$ scaling pathway, serving as a boundary line for hardware resource exhaustion tests.

For the final classification step, DeBERTa extracts the hidden state of the prepended \texttt{[CLS]} token. This specific token representation, designed to aggregate bidirectional context, is then projected through a linear dense layer to generate class probabilities.

\subsection{Patched Transformer Formulation (PatchTST)}
To represent structural optimization, we evaluate PatchTST. Originally configured for long-range sequence data forecasting, the model is adapted here for textual stream analysis by configuring localized patches over adjacent embedding dimensions. By evaluating token sub-blocks rather than individual token pairs independently across the complete document length, the system decreases active memory allocation metrics. The primary experimental concern remains whether these hard segment breaks disturb long-distance syntactic dependencies.

To derive document-level predictions, the network aggregates the processed patch representations via a global pooling mechanism (such as average pooling or flattening). The resulting bounded vector is subsequently fed into a linear classification head to produce the final outputs.

\subsection{Selective State Space Formulation (Mamba-Cls)}
The third test candidate is Mamba-Cls, an architecture built around discretized continuous state space projections tailored for discriminative tasks. Mamba replaces standard multi-head attention blocks with a continuous selection step that alters the state space matrix components based directly on the historical properties of the current token sequence. This configuration sidesteps the construction of large $n \times n$ attention structures, keeping memory consumption stable across variable sequence envelopes.

Unlike attention mechanisms that rely on global token aggregation or \texttt{[CLS]} tokens, Mamba's classification strategy leverages the final token's hidden state. Because the selective state space dynamically filters and accumulates historical context along the sequence timeline, this terminal state functions as a sequence summary vector, which is directly passed to the classification head.

\section{Experimental Architecture}

\subsection{Dataset Properties}
All model configurations were systematically tested on the AG News data platform \cite{agnews}. The target dataset spans four semantic domains: World, Sports, Business, and Science/Technology. The task requires choosing one of these four categorical tags for each incoming text document.

\subsection{Local Execution Controls}
To simulate restricted educational or institutional infrastructure, all benchmarking routines were completed using a single-node GPU device (NVIDIA Tesla T4 accelerator with 16GB VRAM) accessible via managed cloud runtimes. Training routines utilized consistent base hyperparameter states across all tested configurations, including an optimization batch sizing constraint of 8 sequences per step and standard learning rate setups. Token limits were formally scaled across four levels: 256, 512, 1024, and 2048 tokens.

\subsection{Assessment Metrics}
Model comparisons are documented via four criteria:
\begin{itemize}
    \item \textbf{Accuracy \& F1-Score:} Tracking model validation correctness.
    \item \textbf{Peak Memory Footprint (MB):} Tracking active GPU VRAM utilization during computation.
    \item \textbf{Processing Throughput (tokens/s):} Evaluating execution velocity.
    \item \textbf{Training Horizon:} Documenting real-world time usage per training epoch.
\end{itemize}

\subsection{Semantic Accuracy Evaluation}
Our records indicate that DeBERTa-v3 maintains a competitive classification profile at intermediate input configurations, registering an accuracy peak of 0.730 at a sequence constraint of 512 tokens. This performance is likely supported by the extensive pre-training knowledge base inherent to the baseline model. However, PatchTST shows a lower accuracy tier across all scaling contexts, hovering within a lower F1 bracket (0.633 to 0.665). This variance suggests that dividing textual sequences into rigid structural patches can disrupt linguistic relationships that contribute to topic identification.

To explicitly address the behavioral limits and performance trends of the tested architectures under constrained conditions, Figure \ref{fig:scaling_plot} illustrates the scaling trajectories across the evaluated token spectrum.

\begin{figure}[ht]
    \centering
    \includegraphics[width=\textwidth]{triple_scaling_plot.pdf}
    \caption{Performance scaling behavior illustrating accuracy variations, memory consumption, and potential saturation points across extending sequence lengths ($L$).}
    \label{fig:scaling_plot}
\end{figure}

For Mamba-Cls, the empirical curve reveals a distinct, non-monotonic scaling pattern regarding semantic accuracy. The network's performance reaches its localized minimum at $L = 512$ tokens (0.701 F1). This initial dip may indicate a transient sensitivity to an altered noise-to-signal ratio as the context window initially expands without sufficient semantic reinforcement. Following this point, the model recovers efficiently, climbing to its maximum observed performance at $L = 2048$ tokens (0.757 F1). 

Regarding performance saturation, the upward trajectory observed between 1024 and 2048 tokens suggests that Mamba-Cls has not yet fully plateaued within our testing boundaries. However, the decreasing rate of marginal improvement indicates that the model is likely approaching a saturation boundary. In practical terms, extending $L$ significantly beyond 2048 tokens is expected to yield diminishing returns, as the core semantic indicators requisite for the AG News classification task are generally adequately captured within this established context window. Further scaling experiments extending towards 4096 tokens, hardware permitting, would be required to empirically map the exact horizontal asymptote of this architecture.

\subsection{Computational Scaling Behavior}
The real-world impacts of the $\mathcal{O}(n^2)$ mathematical bottleneck are visible within DeBERTa's operational trajectory. Moving from 256 tokens to 1024 tokens causes its VRAM demands to rise from 1715MB to 2845MB, while its processing throughput declines from 56,135 tokens/s to 9,487 tokens/s. When attempting to run the model at the 2048-token limit, the dense attention system encounters an Out-of-Memory (OOM) exception, stopping training tasks.

In comparison, Mamba-Cls demonstrates stable hardware scaling behavior. Its peak memory consumption remains relatively flat across the entire test spectrum, requiring 153MB at 256 tokens and remaining at 151MB at 2048 tokens. At the maximum context length of 2048 tokens, Mamba-Cls maintains an operational processing throughput of 118,000 tokens/s continuing to train without encountering the memory walls that impact dense Transformers on the same hardware setup. While PatchTST achieves a marginally higher throughput rate at the 2048 token boundary, its computational advantage is accompanied by lower downstream classification accuracy.

\section{Limitations}
Given its framing as a localized academic pilot study, several analytical constraints must be highlighted:
\begin{enumerate}
    \item \textbf{Dataset Scope:} Evaluation routines were isolated to the AG News benchmark dataset. Tests across highly specialized textual distributions (such as legal or medical corpora) are necessary to further generalize these findings.
    \item \textbf{Disparities in Baseline Scales:} DeBERTa leverages large-scale contextual pre-training, while our local Mamba run relies on a smaller, task-specific random parameter initialization. This structural imbalance may affect performance comparisons within shorter token contexts.
    \item \textbf{Hardware and Scope Specificity:} The documented resource thresholds are specific to the architectural properties of the local graphics hardware utilized for this evaluation.
\end{enumerate}

% ==========================================
% 6. CONCLUSION
% ==========================================
\section{Conclusion}
This small-scale empirical exercise highlights the real-world resource trade-offs dividing alternative sequence processing models within text classification boundaries. Pre-trained dense attention architectures provide robust classification accuracy in shorter segments but exhibit significant resource demands at expanded context levels, resulting in hardware execution limits under resource-constrained conditions. Structural patch attempts successfully manage VRAM costs but show lower overall categorization accuracy due to their segmented token structures.

Under our local institutional test conditions, Mamba-Cls presents a balanced profile, maintaining stable hardware memory requirements ($\sim$151MB VRAM) and robust operational processing speeds while supporting performance scalability up to 2048 tokens. This behavior indicates that Selective SSM structures can serve as viable, efficient architectural alternatives for long-document textual classification research within constrained local academic computational ecosystems.
